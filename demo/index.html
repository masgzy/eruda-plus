Eruda 增强版 Network 面板演示

本页面加载了增强版 eruda（Network 面板重构版）。点击右侧悬浮按钮打开 eruda，切到 Network 面板，再点下面的按钮发起请求，观察：统计概览条、失败过滤、请求重放、cURL 复制、HAR 导出、请求阻断、DevTools 风格详情（Headers / Cookies / Request / Response / Timing 瀑布图）。

阻断演示：点击「查看阻断规则」填入规则并开启（已自动配置拦截 /api/track），再点「触发被阻断请求」— 请求不会发到服务器，列表中以 blocked 标记。
重放演示：列表中点击任意请求 → 详情页 → 点 ▶（Replay）。
