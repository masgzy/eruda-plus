eruda-plus

为移动端网页而生的浏览器控制台

一行脚本，让任何手机网页拥有 Chrome DevTools 级调试能力。增强版 Network 面板支持请求屏蔽、重写、Mock 与节流，全工具中英文一键切换。

在线实测 GitHub
eruda.cc.cd/demo — 下方页面已加载 eruda-plus，点右下角齿轮打开控制台 新窗口打开 ↗

提示：在下方页面点按钮发起请求，再打开 eruda → Network 面板查看 / 屏蔽 / 重写 / Mock / 节流。iframe 内也可直接拖动、缩放、切换中英文。

特性

不只是换肤。eruda-plus 在 eruda 之上重构了 Network 面板，并为全部工具带来 i18n 与 DevTools 级视觉细节。

🛰

DevTools 级 Network

逐请求彩色瀑布图、时序概览带、状态码着色、Initiator 与 Timing 分解，对齐 Chrome DevTools 的信息密度。

🚧

屏蔽 / 重写 / Mock

黑名单直接拦下请求并模拟 403；URL 重写与 Mock 规则实时生效，被拦截与合成响应均有明确标记。

📶

网络节流

Slow 3G / Fast 3G / 离线一键切换，复现弱网下的页面表现，无需额外代理工具。

💾

HAR 导入导出

与桌面 DevTools 无缝互通：把抓包结果导出为标准 HAR，或将桌面抓包导入到手机继续分析。

🌐

全工具中英文

术语与 Chrome DevTools 官方中文逐一对照（标头、载荷、启动器、瀑布…），跟随系统语言，亦可手动切换。

🔎

补齐能力

Live Expressions 实时表达式、DOM 搜索、Preserve Log 保留日志、请求重放与 cURL/fetch 一键复制。

快速上手

在任意网页的控制台里粘贴以下代码，立即获得增强版控制台。

javascript
// 方式一：CDN 直接加载（jsDelivr，已发布版本）
const s = document.createElement('script')
s.src = 'https://cdn.jsdelivr.net/gh/masgzy/eruda-plus@0.1.0/dist/eruda.js'
s.onload = () => eruda.init()
document.head.appendChild(s)

// 方式二：先增强 Network 面板再初始化
s.onload = () => {
  eruda.init()
  eruda.add(eruda.networkPlus)   // 独立插件版（可选）
}
